## 📸 About the Project

This portfolio website is designed to present my frontend development skills and projects in a clean, modern, and user-friendly interface.

## ⚙️ Installation & Setup

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/muzammil-developer/My-Portfolio/tree/main
   ```

2. Open the project folder:

   ```bash
   cd portfolio
   ```

3. Open the folder in Visual Studio Code.

4. Run `index.html` using Live Server.

## 📧 Contact Form Setup

The contact form uses EmailJS to send messages directly to my email.

To enable email functionality:

1. Create an account on EmailJS.
2. Connect your Gmail service.
3. Create an email template.
4. Add your EmailJS Public Key, Service ID, and Template ID to `script.js`.

**Note:** The contact form requires valid EmailJS configuration to send messages.
